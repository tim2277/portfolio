This is a sample project. It exists so the `projects` schema has something to
validate against. It's `draft: true`, so it renders in `astro dev` and is left
out of a production build.

Projects carry three fields posts don't:

- `status` — one of `active`, `shipped`, `archived`, `exploration`
- `repo` — optional source link
- `url` — optional live link

## The shape of a good project write-up

Lead with the decision, not the feature list. What was the constraint, what did
you rule out, and what did it cost you? A screenshot tells a reader what it
looks like; the trade-off tells them whether you can think.

## Constraints

- Static output only, no server
- Free hosting tier
- Zero client JS on a content page
