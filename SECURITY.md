# Security Policy

This covers the code in this repository and the site it builds,
[timwrites.dev](https://timwrites.dev).

If you find a vulnerability, please report it privately using GitHub's
[private vulnerability reporting](https://github.com/tim2277/portfolio/security/advisories/new)
for this repository, rather than opening a public issue. There's no email
route for this — the domain publishes a null MX record and accepts no mail.

This is a personal site with no bounty programme, but a genuine report will
get a prompt reply and a fix.
